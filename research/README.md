## How to use

When researching a new composition:
1. Create a new folder under `research/` named with a short slug.
2. Add a `README.md` summarizing findings, sources, and open questions.
3. Add a `next-steps.md` with practical guidance for obtaining deposits or further materials.
4. Store any transcripts, catalog excerpts, or related notes in that folder.
5. Update the table above.
6. Add the work to the tracking log in [copyright-office-actions.md](copyright-office-actions.md) when preparing a request.
