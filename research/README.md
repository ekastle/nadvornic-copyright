# Research Notes

This directory holds research notes on individual musical works associated with Frank Nadvornik. Each work has its own subfolder so findings can be extended over time.

## Works

| Work | Year | Folder | Status |
|------|------|--------|--------|
| God Save America | 1941 | [god-save-america/](god-save-america/) | Initial research complete |
| Christmas Chants (arrangement) | 1946 | [christmas-chants/](christmas-chants/) | Initial research complete |

## How to use

When researching a new composition:
1. Create a new folder under `research/` named with a short slug (e.g. `god-save-america/`).
2. Add a `README.md` summarizing findings, sources, and open questions.
3. Store any transcripts, catalog excerpts, or related notes in that folder.
4. Update the table above.
