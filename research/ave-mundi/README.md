# Ave Mundi (1926)

**Research status:** Initial documentation from family scan; catalog lookup pending.  
**Last updated:** 2026-11-15

## Summary

Musical composition registered by Frank Nadvornik. Words by Joseph Horpesty; music by Frank Nadvornik. One of the certificates found with the inner envelope materials from the Dickinson, North Dakota period.

| Field | Value |
|-------|-------|
| Title | Ave Mundi |
| Words | Joseph Horpesty |
| Music | Frank Nadvornik |
| Publication date | March 7, 1926 |
| Registration | Class E, XXc, No. 473682 |
| Place | Dickinson, North Dakota (associated with earlier materials) |

## Context

This work extends the pattern of musical composition by Nadvornik into the mid-1920s. The Latin title suggests a sacred or hymn-like piece. It was produced while he was still associated with the Dickinson area, before his later activity in Scio, Oregon.

No digitized score or significant online references to this specific composition have been located. The deposited copies remain with the U.S. Copyright Office.
