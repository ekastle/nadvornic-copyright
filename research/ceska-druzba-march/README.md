# Česká Družba March (Czech Friendship March) (1921)

**Research status:** Initial documentation from family scan; catalog lookup pending.  
**Last updated:** 2026-11-15

## Summary

Musical arrangement registered by Frank Nadvornik in Dickinson, North Dakota. One of the early 1921 certificates found with the inner envelope. Copyright was claimed on the arrangement.

## Key facts (from certificate transcription)

| Field | Value |
|-------|-------|
| Title | Česká Družba March |
| English rendering | Czech Friendship March |
| Arranger / Claimant | Frank Nadvornik |
| Type | Arrangement (copyright claimed on arrangement) |
| Publication date | March 6, 1921 |
| Registration | Class E, XXc, No. 505731 |
| Place | Dickinson, North Dakota |

## Context

Produced during the same period as *Československý Bílý Pochod*, this work further illustrates Nadvornik’s activity arranging or composing Czech-themed music for local community use in the early years after Czechoslovak independence. Dickinson, ND, had an active Czech immigrant population.

No digitized score or significant online references to this specific arrangement have been located. The deposited copies remain with the U.S. Copyright Office.
